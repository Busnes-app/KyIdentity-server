# KyIdentity manual

The suite identity provider and central directory. KyIdentity manages accounts, OIDC application registrations, MFA devices and downstream provisioning. Each product still enforces its own application roles and content permissions.

Start with [Getting started](getting-started.md), then [Everyday tasks](using.md).
Use [Troubleshooting](troubleshooting.md) when something fails. [Reference](reference.md)
links the detailed configuration, recovery and security documents for this product.

This manual describes the checked-out product and its documented limits. Release availability,
real-device support and production qualification must be checked for the version you install.
Roadmap and design documents describe proposals unless the product documentation says they shipped.
