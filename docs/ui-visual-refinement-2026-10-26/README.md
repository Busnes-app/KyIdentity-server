# KyIdentity visual refinement (2026-10-26)

One bounded batch from the round-3 release review (`ky-ui` PR 22, `reviews/2026-10-26-fleet/release-review.md`, gap 2). It covers shell, task view and form hierarchy only: no feature, route, copy, role or authorization change, and no Go change. Ratings belong to the independent reviewer; this record claims no score.

## Font: a fixture artifact, not a product defect

Round 3 saw an Arial-like face. The server serves `./css` and `./fonts` from its working directory. The image's `WORKDIR /` provides both, but the 2026-10-26 fleet capture driver started the binary in a bare scratch directory, so `/css/styles.css` and every `/fonts/*` request returned 404 and the browser fell back to a generic sans. This batch's driver links the repository's `css/` and `fonts/` into the scratch directory and records each capture's loaded web fonts (`loaded_fonts`). Every capture here, BEFORE included, loaded Space Grotesk and IBM Plex Mono. The type change between round-3 images and these is fixture drift, not a product improvement.

A genuine product defect did show once the fonts loaded. The pre-bundle `/css/styles.css`, which `index.html` also links, sets `.brand { font-family: mono }`, so the app wordmark rendered in IBM Plex Mono. The app's own `index.css` now sets the display face on `.brand`.

## Changes

- **Users** (`AdminUsers.tsx`):
  - Each row's nine icon-only actions are now one labelled "Manage" disclosure (native `<details>`). Inside, each action shows its name and icon. Delete user is set apart in the danger colour.
  - All handlers, `disabled` guards, role conditions and step-ups are unchanged. Two accessible names now contain their visible label (Delegated administration, Sessions and apps).
  - On phones the table becomes labelled blocks, so email, role, status and actions stay on screen.
  - The table keeps its semantics: the headers are visually hidden and the cells are labelled. `table-roles.mjs` (output in `table-roles.txt`) shows Chromium 153 keeps the table, row, column-header and cell roles under this CSS. Cell names include the visible label ("Account admin").
- **Shell:**
  - The "ID Authority" descriptor is quiet secondary text, not an orange uppercase mono eyebrow; the copy is unchanged.
  - The wordmark uses the display face.
  - Navigation shows only the shared ky-ui current rail: the local 2px left border is removed, which had doubled it on desktop and outlined the phone pill.
- Shared catalog, colours, fonts, storage keys, CSP and every other surface are unchanged.
